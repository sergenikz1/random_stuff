# random_stuff

Сборник небольших независимых продуктов. **Каждый продукт живёт в своей ветке.** Ветки не сливаются
ни друг с другом, ни в `main`. В `main` лежат только это описание и общая автоматизация репозитория.

Чтобы поработать с продуктом, переключитесь на его ветку, например `git checkout limit-pulse`.
В корне каждой ветки есть свой README.

## Релизы: только последняя версия каждого продукта

- Сборки делает GitHub Actions. Workflow каждого продукта лежит в его ветке в `.github/workflows/`.
- **В разделе Releases хранится только последняя версия каждого продукта.** Старые версии вместе с их тегами
  удаляет workflow [«Чистка релизов»](.github/workflows/releases-cleanup.yml) из `main`.
  Он запускается при изменении своего файла и вручную: Actions → «Чистка релизов» → Run workflow.
  Запускайте его после выхода новой версии любого продукта.
- Продукт определяется по тегу релиза без номера версии: `chitalka-v1.3` → `chitalka`,
  `limit-pulse-v0.3.0` → `limit-pulse`, `scan2onec-v1.0.0` → `scan2onec`.
- Релизы без номера версии (`apk-latest`, `flowvoice-latest`) — «плавающие»: каждая сборка перезаписывает
  в них файлы, поэтому у них всегда одна, свежая версия.
- 23.10.2026 удалены старые версии: Читалка вслух 1.0–1.2 и Limit Pulse 0.1.0–0.2.0.

## Как добавить новый продукт

1. Создайте ветку с коротким названием продукта латиницей через дефис: `git checkout --orphan my-product`.
2. Положите код в папку продукта, README — в корень ветки, workflow сборки — в `.github/workflows/`.
3. Публикуйте релизы с тегом вида `<продукт>-v<версия>`, тогда чистка релизов подхватит продукт сама.
4. Добавьте строку в таблицу выше в ветке `main`.
