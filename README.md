# mail-audit

Набор скриптов, чтобы понять, из чего на самом деле состоит поток рабочей почты в Mail.ru:
кто пишет, о чём, как быстро отвечают, что висит без ответа и какую долю работы можно автоматизировать.

## Как это работает

1. **Выгрузка в браузере.** Скрипт `browser/mailru-export.js` запускается в консоли браузера на e.mail.ru,
   обходит все папки и скачивает письма одним файлом `.ndjson`. Пароль и токены никуда не передаются.
2. **Анализ на компьютере.** `analyze/analyze.py` считает статистику и метрики и делает отчёт `report.html` и CSV.
   Ничего не отправляет в интернет.
3. **Разбор по процессам (по желанию).** `analyze/classify_llm.py` с помощью Claude API группирует письма
   в рабочие процессы и оценивает, что можно автоматизировать. На этом шаге письма уходят в Claude API.

Пошаговая инструкция и все команды — в [mail-audit/README.md](mail-audit/README.md).

## Устройство ветки

| Путь | Что там |
|---|---|
| `mail-audit/browser/` | Скрипт выгрузки для консоли браузера |
| `mail-audit/analyze/` | Скрипты анализа на Python |
| `index.html`, `server.js`, `Dockerfile` | Остались от [Vibrate](../../tree/vibrate-tg), к mail-audit не относятся |

Сборок и релизов нет: это скрипты, которые запускаются как есть.

Это ветка продукта из репозитория [random_stuff](../../tree/main), где каждый продукт живёт в своей ветке.
