# RuTV

Неофициальный клиент Rutube для Android TV и приставок, управляется с пульта.
Реклама не проигрывается: приложение берёт из ответа Rutube только адрес видеопотока и играет его в ExoPlayer.

- Главный экран в стиле Android TV: «Продолжить просмотр», «Избранное», закреплённые каналы, новое на Rutube.
- Поиск, в том числе голосовой с пульта.
- Плеер с прямыми эфирами, перемоткой ±10 с и продолжением с места остановки.
- Избранное и история хранятся на устройстве, аккаунт не нужен.

## Скачать

Свежий APK всегда лежит в предрелизе [`apk-latest`](../../releases/tag/apk-latest):
каждая сборка из этой ветки перезаписывает его.

## Устройство ветки

| Путь | Что там |
|---|---|
| `android/` | Приложение (Kotlin, Gradle). Подробное описание и подпись релизным ключом — [android/README.md](android/README.md) |
| `.github/workflows/android.yml` | Сборка APK на каждый push в `android/` и публикация в `apk-latest` |
| `index.html`, `server.js`, `Dockerfile` | Остались от [Vibrate](../../tree/vibrate-tg), к RuTV не относятся |

## Сборка

```sh
cd android
./gradlew assembleRelease
```

Это ветка продукта из репозитория [random_stuff](../../tree/main), где каждый продукт живёт в своей ветке.
