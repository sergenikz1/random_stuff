# Читалка вслух

Android-приложение: читает электронные книги вслух системным синтезатором речи
и одновременно подсвечивает озвучиваемый текст, чтобы можно было слушать и следить глазами.

Работает **полностью офлайн** — разрешение `INTERNET` приложению не выдано вовсе
(см. `app/src/main/AndroidManifest.xml`), поэтому оно физически не может ничего никуда отправить.

## Возможности

| Что | Как сделано |
|---|---|
| Форматы книг | EPUB, FB2, FB2.ZIP, PDF с текстовым слоем, TXT, HTML/XHTML, Markdown |
| Библиотека | Список книг с обложкой прогресса, продолжением с места остановки и удалением |
| 3 голоса | Три встроенные нейросетевые модели (Ирина, Денис, Руслан) — синтез прямо на телефоне |
| Пауза и перемотка | Кнопка ▶/⏸ в верхней панели; ±предложение, ±глава и ползунок по книге — в настройках (⚙ справа вверху), переход по тапу на предложение |
| Быстрое чтение | Слова по одному в фиксированной точке, опорная буква красная (как Spritz), 100–1000 слов/мин, плавный разгон, паузы на знаках препинания. Позиция общая с обычным чтением |
| Только текст | Без панелей и системных полос; тап по тексту на 4 секунды показывает кнопки, «Назад» — выход из режима |
| Музыка во время чтения | «Не трогать» — сторонний плеер играет дальше; «Приглушать» — музыка тише, пока звучит голос; «Ставить на паузу» — как раньше |
| Подсветка чтения | Прочитанное — приглушённое, текущее предложение — светлое с подложкой, текущее слово — акцентом |
| Объём текста на экране | 5 режимов от «Минимум» до «Вся книга» + размер шрифта и межстрочный интервал |
| Фоновая работа | Foreground-служба с уведомлением: пауза, предложение назад/вперёд при выключенном экране |
| Кодировки | Автоопределение UTF-8 / windows-1251 / KOI8-R — русские TXT и FB2 не превращаются в «кракозябры» |

## Установка

Готовый APK лежит в [Releases](https://github.com/sergenikz1/random_stuff/releases).
Внутри репозитория он не хранится: около 250 МБ из-за встроенных моделей синтеза речи.

Сборки промежуточных коммитов можно забрать из артефактов CI:
вкладка Actions → запуск **Android Reader APK** → артефакт `chitalka-vsluh-arm64`.

Собираются два APK: `arm64-v8a` (все современные телефоны) и `armeabi-v7a` (старые 32-битные).
На телефоне нужно разрешить установку из неизвестных источников, затем открыть файл.

Минимальная версия Android — 8.0 (API 26).

## Голоса

В приложение встроены три нейросетевые модели синтеза речи (VITS, обученные в проекте
[Piper](https://github.com/rhasspy/piper), запуск через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)):

| Голос | Тембр | Размер модели |
|---|---|---|
| Ирина | женский, спокойный | 63 МБ |
| Денис | мужской, мягкий | 63 МБ |
| Руслан | мужской, чёткий | 63 МБ |

Синтез идёт целиком на устройстве, интернет не нужен ни на первом запуске, ни потом.
Предложение синтезируется на шаг вперёд, пока звучит предыдущее, поэтому пауз между фразами нет.

При первом включении голос распаковывается из APK во внутреннюю память (на это уходит
несколько секунд и ещё 63 МБ места). Ненужный голос можно удалить из памяти на экране «Голоса»
кнопкой «Освободить место» — сам APK при этом не меняется, голос можно вернуть в любой момент.

Для книг **не на русском** используется системный движок Android: встроенные модели обучены
только на русском. Системные голоса выбираются там же, на экране «Голоса», и для них
дополнительно доступна регулировка высоты тона (у нейросетевых моделей тембр задан обучением).

## Сборка из исходников

```bash
export ANDROID_HOME=/путь/к/android-sdk
./gradlew :app:assembleDebug          # APK: app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest      # тесты разборщиков форматов
```

Новый релиз публикуется по тегу: `git tag chitalka-v1.1 && git push origin chitalka-v1.1` —
workflow соберёт оба APK и выложит их в Releases.

Требуется JDK 17+, Android SDK с platform 35 и build-tools 35.

## Устройство проекта

```
parse/     разбор форматов: EPUB (container.xml → OPF → spine), FB2, PDF (PDFBox), HTML, TXT
text/      нарезка на предложения через BreakIterator + принудительная нарезка длинных фраз
tts/       NeuralTtsBackend  — VITS через sherpa-onnx + AudioTrack, синтез на шаг вперёд
           SystemTtsBackend  — системный движок Android, запасной вариант и другие языки
           VoiceInstaller    — распаковка моделей из assets во внутреннюю память
player/    PlayerEngine — позиция в книге, выбор движка речи, аудиофокус
           PlaybackService — уведомление и работа при выключенном экране
data/      библиотека книг (JSON), кэш разобранного текста, настройки
ui/        Jetpack Compose: библиотека, читалка, экран голосов
```

Разобранный текст кэшируется при импорте, поэтому повторное открытие книги мгновенное.

Модели и библиотека sherpa-onnx в репозитории не хранятся: задача Gradle `fetchTtsAssets`
скачивает их с Hugging Face при первой сборке. Данные фонемизатора espeak-ng лежат
в `tts-assets/espeak-ng-data.zip` и распаковываются в ассеты той же задачей.

## Ограничения

- PDF озвучивается только при наличии текстового слоя; сканы страниц без OCR не поддерживаются.
- MOBI / AZW3 не поддерживаются.
- Пауза останавливает предложение целиком: после продолжения текущее предложение
  читается с начала.
- Подсветка слова у нейросетевых голосов приблизительная: модель не сообщает границы слов,
  положение считается из позиции воспроизведения и длины предложения. У системного движка
  подсветка точная (`onRangeStart`).
- Первый запуск голоса требует нескольких секунд на загрузку модели в память.
