# Limit Pulse — Android-виджет лимитов Codex

Небольшое независимое приложение для Android 8.0+ без рекламы, аналитики и собственного сервера. Исходная Telegram-страница в корне репозитория остаётся отдельным приложением.

## Что показывает

- Остаток Codex в процентах для основного и дополнительного окна, продолжительность окна и время сброса.
- План аккаунта, дополнительные лимиты и кредиты, если OpenAI возвращает эти поля.
- Время последнего успешного запроса. Сохранённые данные явно помечаются при ошибке, через 30 минут или после указанного сброса. Приложение не придумывает восстановление лимита.
- Виджет главного экрана с обновлением по кнопке и примерно раз в 30 минут. Doze, ограничения батареи и производитель телефона могут задерживать фоновые обновления.

**Точный остаток сообщений ChatGPT не поддерживается.** OpenAI не предоставляет этому приложению API такого счётчика. Виджет и экран показывают это ограничение и открывают ChatGPT для проверки доступности моделей. Лимиты API OpenAI и платёжный баланс API — отдельные данные; API-ключ не заменяет подписку ChatGPT и здесь не нужен.

## Установка и вход

1. Скачайте подписанный `limit-pulse-v0.1.0.apk` из GitHub Releases и разрешите установку этому браузеру/файловому менеджеру.
2. Нажмите «Войти через OpenAI». Приложение запросит одноразовый код устройства.
3. Откройте `https://auth.openai.com/codex/device` кнопкой приложения, войдите в браузере и введите показанный код. Подтверждайте только вход, который вы начали самостоятельно.
4. Вернитесь в Limit Pulse. Ожидание подтверждения ограничено 15 минутами. Если Android завершил приложение, начните вход заново.
5. Нажмите «Добавить виджет на экран» либо выберите Limit Pulse в списке виджетов лаунчера.

В настройках безопасности ChatGPT должен быть разрешён вход Codex по коду устройства. Этот вход выдаёт токены Codex, а не отдельный токен с разрешением только на чтение лимитов. Само приложение использует их исключительно для запросов лимитов и обновления сессии. Не передавайте токены другим людям.

## Источник данных и ограничения

Авторизация и формат данных основаны на опубликованном исходном коде [OpenAI Codex](https://github.com/openai/codex):

- [Официальная документация входа](https://developers.openai.com/codex/auth).
- [Device-code flow](https://github.com/openai/codex/blob/main/codex-rs/login/src/device_code_auth.rs), публичный OAuth client ID из `codex-rs/login/src/auth/manager.rs`.
- [Запрос лимитов](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client/rate_limit_resets.rs): `GET https://chatgpt.com/backend-api/wham/usage`.

Это экспериментальный сторонний клиент, не официальное приложение OpenAI и не зарегистрированная отдельная OAuth-интеграция. Доступность входа, структура ответа и правила доступа могут измениться. Ошибки 401/403/429 не скрываются; сохранённые значения не выдаются за свежие. До публикации проверены получение кода устройства без входа в личный аккаунт, тесты протокола с моделируемыми ответами и Android-интерфейс. Полный вход и реальные лимиты конкретной подписки требуют проверки владельцем аккаунта на телефоне.

## Приватность

Пароль вводится только в браузере OpenAI. Access/refresh tokens шифруются AES-GCM; ключ хранится в Android Keystore, шифротекст — в закрытых настройках приложения. Резервное копирование и перенос данных приложения отключены. Токены не попадают в логи, Git, APK или GitHub Releases. Перенаправления авторизованных запросов запрещены, HTTPS проверяется штатным Android trust store. Приложение обращается только к `auth.openai.com` и `chatgpt.com`. На «Отключить аккаунт» удаляются локальные токены и кеш; это не глобальный выход из аккаунта OpenAI.

## Сборка

Нужны JDK 17+ (проверено на JDK 21), Android SDK Platform 35 и Build Tools 35.0.0. Gradle 8.11.1 и Android Gradle Plugin 8.9.2 зафиксированы; wrapper проверяет SHA-256 дистрибутива.

```sh
cd android
export ANDROID_HOME=/path/to/android-sdk
./gradlew --no-daemon testDebugUnitTest lintRelease assembleRelease
```

Результат — `app/build/outputs/apk/release/app-release-unsigned.apk`. Для локальной отладки используйте `./gradlew assembleDebug` и `adb install -r app/build/outputs/apk/debug/app-debug.apk`. CI проверяет тесты, lint и release-сборку, сохраняет **неподписанный** APK как артефакт; он не является устанавливаемым релизом.

Подписать release своим ключом:

```sh
export LIMITPULSE_KEYSTORE=/secure/path/limit-pulse.jks
export LIMITPULSE_PASSWORD_FILE=/secure/path/keystore-password.txt
bash scripts/sign-release.sh
```

Пароль считывается из защищённого файла, не из аргументов командной строки. Подпись проверяется `apksigner verify`; итоговый APK, SHA256SUMS и публичный сертификат создаются в `app/build/outputs/release/`. **Для обновления поверх установленного APK требуется тот же ключ подписи.** Ключ первого выпуска сохранён вне репозитория в облачной рабочей среде; ключ и пароль никогда не публикуются в Releases. Перед удалением среды сохраните их отдельно в защищённом хранилище.

## Проверки

JUnit проверяет отсутствие данных, вычисление остатка, истечение окна, дополнительные лимиты, код устройства, обмен токенов, идентичность аккаунта при refresh, единственный повтор после 401, отсутствие повтора при 403 и остановку при ошибке сохранения rotating token. Robolectric на Android API 26 и 35 проверяет запуск Activity, переход в ChatGPT и содержимое RemoteViews виджета. SDK для этих тестов получает Gradle; тесты используют локальные артефакты и не пишут в домашнюю папку пользователя. Эти проверки не заменяют вход в личный аккаунт, проверку Android Keystore на физическом устройстве и поведение фоновых задач конкретного производителя.
