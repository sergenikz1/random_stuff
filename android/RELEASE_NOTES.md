В **Limit Pulse 0.2.0** основным стал обычный вход через браузер OpenAI: переписывать код устройства больше не нужно.

### Как войти

1. Установите `limit-pulse-v0.2.0.apk` поверх предыдущей версии. Ключ подписи тот же; аккаунт, кеш и виджет сохраняются.
2. Нажмите «Войти через браузер» и войдите на странице OpenAI привычным способом.
3. Браузер вернёт вас в приложение. Если автоматический возврат заблокирован браузером, нажмите «Вернуться в приложение» на странице завершения.

Ожидание входа ограничено 10 минутами, с временной службой для работы во время открытого браузера. Вход можно отменить. Старый способ «Код устройства» оставлен как запасной; разрешать вход по коду в настройках ChatGPT требуется только для него.

### Проверено

- **35 тестов**, без пропусков: PKCE (RFC 7636), реальный loopback callback, проверка `state`, отмена и тайм-аут, формат обмена кода на токены, возврат в Android, уведомление службы, виджет и прежняя логика лимитов.
- `lintRelease` без замечаний и `assembleRelease` успешно.
- Подпись v2/v3 тем же RSA-3072 ключом; package `dev.limitpulse.app`, versionCode 2, Android 8.0+.
- OpenAI принимает browser authorization URL и перенаправляет на свою страницу входа (HTTP 302).

Полный вход в конкретный личный аккаунт и возврат из браузера на физическом телефоне требуют проверки владельцем. Авторизация основана на опубликованном клиенте Codex; приложение независимое, не официальное приложение OpenAI.

Лимиты Codex и виджет поддерживаются, **точный счётчик оставшихся сообщений ChatGPT по-прежнему недоступен**. Токены шифруются Android Keystore; пароль вводится только в браузере OpenAI. Приватный ключ подписи и данные аккаунтов не передаются в GitHub.

Вложения: подписанный APK, `SHA256SUMS`, публичный сертификат. Исходники: ветка `feat/android-openai-limits-widget`, каталог `android/`.
