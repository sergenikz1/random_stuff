Первый предварительный выпуск **Limit Pulse** — независимого приложения и виджета главного экрана для Android 8.0+.

**Поддерживается остаток лимитов Codex. Точный остаток сообщений ChatGPT недоступен:** приложение прямо показывает это ограничение и открывает интерфейс ChatGPT. Это не счётчик лимитов OpenAI API и не официальное приложение OpenAI.

### Установка

1. Скачайте `limit-pulse-v0.1.0.apk` и разрешите установку выбранному браузеру или файловому менеджеру.
2. Нажмите «Войти через OpenAI», откройте браузер кнопкой приложения и подтвердите показанный одноразовый код на `auth.openai.com/codex/device`.
3. Вернитесь в приложение и добавьте виджет на главный экран. В настройках безопасности ChatGPT должен быть разрешён вход Codex по коду устройства.

### Возможности

- Остаток Codex в процентах, основное/дополнительное окно, время сброса и последнего обновления.
- План аккаунта, дополнительные лимиты и кредиты, когда эти данные возвращает OpenAI.
- Виджет с ручным обновлением и фоновым обновлением примерно каждые 30 минут. Android может задерживать фоновые задачи.
- Явная пометка сохранённых/устаревших данных; отсутствие данных не заменяется вымышленными 100%.
- Шифрование токенов AES-GCM через Android Keystore; отключённое резервное копирование. Без аналитики, рекламы и собственного сервера.

### Проверено

- `testDebugUnitTest`: **24 теста прошли**, без пропусков; логика лимитов и OAuth, Activity и RemoteViews на Android API 26 и 35.
- `lintRelease`: без замечаний; `assembleRelease`: успешно.
- APK подписан RSA-3072, подпись v2/v3 проверена `apksigner`; package `dev.limitpulse.app`, версия `0.1.0`, minSdk 26, targetSdk 35.
- OpenAI отвечает HTTP 200 на начальный запрос кода устройства; источник лимитов отвечает HTTP 401 без авторизации.

Полный вход в личный аккаунт и реальные лимиты подписки требуют проверки владельцем на телефоне. Проверка Android Keystore на физическом устройстве и фоновая работа конкретного лаунчера здесь не выполнялись. Вход и источник лимитов основаны на открытом клиенте Codex, не являются стабильным публичным API для сторонних приложений и могут измениться.

Вложения: устанавливаемый подписанный APK, `SHA256SUMS` и публичный `signing-certificate.pem`. Ключ подписи, его пароль и токены аккаунтов не публикуются. Для следующих обновлений нужно сохранить оригинальный приватный ключ подписи вне репозитория.

Исходники и инструкции: ветка `feat/android-openai-limits-widget`, каталог `android/`.
