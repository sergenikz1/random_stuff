# FlowVoice

Клон Wispr Flow: голосовой ввод, который печатает текст туда, где стоит курсор.
Поддерживает **русский и английский** — включая режим «Авто», когда язык
определяется сам и вы можете свободно переключаться между ними в одной фразе.

Два приложения из одного репозитория:

| Платформа | Что собирается | Как это работает |
|---|---|---|
| **Windows** | `FlowVoice-Setup-1.0.0-x64.exe` (установщик) и `FlowVoice-Portable-1.0.0-x64.exe` | Приложение в трее. Горячая клавиша → запись → расшифровка → текст вставляется в активное окно |
| **Android** | `FlowVoice-1.0.0.apk` | Приложение + **голосовая клавиатура** (IME): кнопка микрофона вставляет надиктованное прямо в любое поле ввода |

---

## Где взять готовые файлы

Сборка идёт в GitHub Actions (`.github/workflows/flowvoice.yml`).
Каждый push собирает `.exe` на Windows-раннере и `.apk` на Linux-раннере и
выкладывает их в rolling-предрелиз **`flowvoice-latest`** на вкладке Releases.
Их же можно скачать во вкладке Actions как артефакты сборки.

Обе сборки не подписаны сертификатом разработчика, поэтому при первом запуске
Windows SmartScreen и Android покажут предупреждение («Всё равно запустить» /
«Установить из неизвестного источника»).

## Как пользоваться

### Windows

1. Установите и запустите — откроется окно настроек, значок появится в трее.
2. На вкладке **Основное** выберите движок и вставьте API-ключ.
3. Поставьте курсор в любое поле ввода в любой программе.
4. Нажмите `Ctrl + Shift + Space`, говорите, нажмите ещё раз (или просто
   замолчите — запись остановится сама). Текст напечатается за вас.

`Esc` отменяет запись. Горячая клавиша меняется на вкладке **Захват**.

### Android

1. Откройте приложение, вставьте API-ключ (или выберите движок
   **«На устройстве»** — он бесплатный и работает офлайн).
2. Разрешите доступ к микрофону — нажмите большую кнопку микрофона.
3. Для диктовки в других приложениях: **Включить в настройках системы** →
   разрешите «FlowVoice — голосовая клавиатура» → **Переключить клавиатуру** →
   выберите FlowVoice.
4. Теперь в любом приложении открываете клавиатуру, жмёте микрофон и говорите.

## Движок распознавания

FlowVoice не привязан к одному провайдеру — подойдёт любой сервис с
OpenAI-совместимым `/v1/audio/transcriptions`. В настройках есть готовые пресеты:

| Пресет | Адрес | Модель |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `whisper-1` |
| Groq | `https://api.groq.com/openai/v1` | `whisper-large-v3` |
| Локально | `http://127.0.0.1:8080/v1` | сервер `whisper.cpp` |

На Android есть ещё режим **«На устройстве»** на базе системного
`SpeechRecognizer`: ключ не нужен, качество ниже, зато бесплатно и без интернета
(если скачан языковой пакет).

### Обработка текста

По желанию расшифровка прогоняется через языковую модель, которая расставляет
знаки препинания, убирает «эээ» и оговорки и пишет слова из вашего личного
словаря так, как нужно. Язык при этом не меняется — перевода не происходит.
Если этот запрос не удался, вставляется исходная расшифровка: диктовка не
теряется никогда.

## Приватность

API-ключ и история хранятся только на вашем устройстве:

* Windows — `%APPDATA%\FlowVoice\settings.json` и `history.json`
  (кнопка «Открыть папку данных» на вкладке **Вставка**);
* Android — приватные `SharedPreferences` приложения.

Аудио уходит только на тот сервер распознавания, который вы указали. В режиме
«На устройстве» оно не покидает телефон вообще.

## Сборка вручную

### Windows (`.exe`)

```bash
cd flowvoice/desktop
npm ci
npx electron-builder --win nsis portable --x64   # результат в dist/
```

Собирать нужно на Windows (или в Windows-раннере CI): NSIS-установщик требует
Windows либо Wine.

### Android (`.apk`)

```bash
cd flowvoice/android
./gradlew :app:assembleRelease            # результат в app/build/outputs/apk/release/
```

Нужны JDK 17 и Android SDK (`compileSdk 35`). Если переменная окружения
`FLOWVOICE_KEYSTORE` не задана, релизная сборка подписывается debug-ключом,
чтобы APK всё равно устанавливался. Для стабильной подписи задайте секреты
репозитория `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` — workflow подхватит их сам.

## Как это устроено

```
flowvoice/
├── desktop/                 Electron, без нативных зависимостей
│   ├── src/main/            главный процесс: горячая клавиша, трей, HTTP, вставка
│   │   ├── main.js          состояние записи и вся оркестровка
│   │   ├── transcribe.js    запрос к Whisper-совместимому API + обработка текста
│   │   ├── paste.js         буфер обмена + Ctrl+V в активном окне
│   │   ├── settings.js      настройки в userData/settings.json
│   │   └── history.js       локальная история диктовок
│   ├── src/preload/         мосты contextBridge
│   └── src/renderer/        плавающая «пилюля» записи и окно настроек
└── android/
    └── app/src/main/java/com/flowvoice/app/
        ├── MainActivity.kt        экран настроек, тестовая диктовка, история
        ├── FlowImeService.kt      голосовая клавиатура (InputMethodService)
        ├── DictationController.kt общий конвейер для экрана и клавиатуры
        ├── WavRecorder.kt         AudioRecord → WAV 16 кГц + остановка по паузе
        ├── DeviceRecognizer.kt    бесплатный офлайн-режим
        ├── Transcriber.kt         OkHttp: транскрипция и обработка текста
        └── Prefs.kt / HistoryStore.kt
```

Вставка текста на Windows сделана через буфер обмена и `SendKeys ^v` из
PowerShell — так сборка обходится без нативных модулей и одинаково собирается
на любом раннере. Прежнее содержимое буфера восстанавливается после вставки.

## Ограничения

* Горячая клавиша работает в режиме «нажал — начал, нажал — закончил».
  Push-to-talk (запись, пока клавиша удерживается) требует низкоуровневого
  перехвата клавиатуры и в этой сборке не реализован; вместо него есть
  автоостановка по паузе.
* Вставка на Windows использует `Ctrl+V`, поэтому не сработает в окнах,
  запущенных от имени администратора, если само приложение запущено без
  повышенных прав. Текст в этом случае остаётся в буфере обмена.
* Приложения не подписаны сертификатом.
