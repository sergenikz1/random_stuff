# Limit Pulse — Android-виджет лимитов Codex и Claude

Небольшое независимое приложение для Android 8.0+ без рекламы, аналитики и собственного сервера. Остальные проекты репозитория лежат в соседних папках и с приложением не связаны.

## Что показывает

- **Claude (Pro/Max)**: остаток 5-часового и недельного лимитов в процентах, отсчёт до сброса, недельные лимиты Opus/Sonnet и дополнительное использование, если Anthropic их возвращает. Отдельный виджет «Limit Pulse · Claude» и напоминания за час до сброса.

- Остаток Codex в процентах для основного и дополнительного окна, продолжительность окна и время сброса.
- План аккаунта, дополнительные лимиты и кредиты, если OpenAI возвращает эти поля.
- Время последнего успешного запроса. Сохранённые данные явно помечаются при ошибке, через 30 минут или после указанного сброса. Приложение не придумывает восстановление лимита.
- Виджет главного экрана с обновлением по кнопке и примерно раз в 30 минут. Doze, ограничения батареи и производитель телефона могут задерживать фоновые обновления.
- Яркие крупные проценты и отсчёт до сброса: часы/минуты для короткого окна, дни/часы для недельного. Локальный отсчёт пересчитывается без запросов к OpenAI; Android может объединять его фоновые обновления для экономии батареи.
- Напоминания за час до сброса каждого окна, с последним известным остатком процентов и временем получения данных. После перезагрузки, обновления приложения и изменения времени напоминания восстанавливаются; после выхода из аккаунта отменяются.

**Точный остаток сообщений ChatGPT не поддерживается.** OpenAI не предоставляет этому приложению API такого счётчика. Виджет и экран показывают это ограничение и открывают ChatGPT для проверки доступности моделей. Лимиты API OpenAI и платёжный баланс API — отдельные данные; API-ключ не заменяет подписку ChatGPT и здесь не нужен.

## Установка и вход

1. Установите подписанный APK. Поверх предыдущей версии он ставится только при совпадении ключа подписи; APK, подписанный другим ключом, требует сначала удалить старую версию (вход и настройки при этом сбрасываются).
2. Нажмите «Войти в OpenAI через браузер». Откроется обычная страница `auth.openai.com`; используйте привычный способ входа, включая Google/Apple, если он доступен для вашего аккаунта.
3. После подтверждения браузер возвращает вас в приложение. Если браузер блокирует автоматический возврат, нажмите «Вернуться в приложение» на странице завершения. Переписывать код устройства не требуется.
4. Во время входа приложение поддерживает временную службу, чтобы Android не завершил ожидание, пока открыт браузер. Ожидание ограничено 10 минутами; его можно отменить в приложении или уведомлении. Если ОС всё же завершила процесс, начните вход заново.
5. Нажмите «Добавить виджет на экран» либо выберите Limit Pulse в списке виджетов лаунчера.

Запасная кнопка «Код устройства» сохраняет старый способ. Только для него нужно разрешить вход Codex по коду устройства в настройках безопасности ChatGPT. Оба способа выдают токены Codex, а не отдельный токен с разрешением только на чтение лимитов. Само приложение использует их исключительно для запросов лимитов и обновления сессии. Не передавайте токены другим людям.

## Claude

Нажмите «Войти в Claude через браузер» в разделе Claude. Откроется страница входа `claude.com` с тем же OAuth-клиентом, что использует Claude Code (Authorization Code + PKCE S256, случайный `state`). После подтверждения браузер вернётся на локальный callback `http://localhost:<порт>/callback` на самом телефоне и затем в приложение. Если браузер не смог открыть локальный адрес, отмените вход и выберите «Запасной способ: вход по коду»: после Authorize страница Claude покажет код вида `код#state` — скопируйте его целиком и вставьте в приложение. Код с чужим `state` отклоняется без сетевого запроса.

Приложение запрашивает только scope `user:profile` — достаточно для чтения лимитов; токен не позволяет отправлять сообщения в Claude, создавать API-ключи или читать чаты. Лимиты читаются запросом `GET https://api.anthropic.com/api/oauth/usage` (заголовок `anthropic-beta: oauth-2025-04-20`): поля `five_hour`/`seven_day` с `utilization` (процент использования) и `resets_at`. Токены Claude хранятся отдельно от токенов OpenAI тем же способом (AES-GCM, ключ в Android Keystore); refresh token обновляется и сохраняется до следующего запроса. «Отключить Claude» удаляет только данные Claude. Это неофициальный клиент: протокол взят из Claude Code и может измениться.

## Напоминания о сбросе

В разделе «За час до сброса» включены напоминания для обоих окон Codex и обоих окон Claude. На Android 13+ нажмите «Разрешить уведомления». Для отправки в указанное время на Android 12+ нажмите «Разрешить точное время» и выдайте системное разрешение приложения. Без него используется разрешённый Android приблизительный будильник; уведомление может прийти позже. Ограничения батареи, выключенный телефон и Doze также могут влиять на доставку.

На каждое окно и время сброса отправляется не более одного уведомления. Если приложение впервые узнало о сбросе менее чем за час, напоминание приходит сразу с реальным оставшимся временем; после прошедшего сброса старое уведомление не отправляется. Если OpenAI изменил время, старый будильник заменяется. Процент берётся из последнего успешного запроса и всегда сопровождается временем этих данных; уведомление не требует сетевого соединения в момент доставки. Переключатель позволяет отключить напоминания.

## Источник данных и ограничения

Авторизация и формат данных основаны на опубликованном исходном коде [OpenAI Codex](https://github.com/openai/codex):

- [Официальная документация входа](https://developers.openai.com/codex/auth).
- [Browser OAuth flow](https://github.com/openai/codex/blob/main/codex-rs/login/src/server.rs): Authorization Code + PKCE (S256), случайный `state`, зарегистрированный loopback callback на `127.0.0.1:1455`. Обработчик принимает только локальные запросы с правильным `state`; deep link возвращает интерфейс и не принимает токены или коды авторизации.
- [Device-code flow](https://github.com/openai/codex/blob/main/codex-rs/login/src/device_code_auth.rs), публичный OAuth client ID из `codex-rs/login/src/auth/manager.rs`.
- [Запрос лимитов](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client/rate_limit_resets.rs): `GET https://chatgpt.com/backend-api/wham/usage`.

Это экспериментальный сторонний клиент, не официальное приложение OpenAI и не зарегистрированная отдельная OAuth-интеграция. Доступность входа, структура ответа и правила доступа могут измениться. Ошибки 401/403/429 не скрываются; сохранённые значения не выдаются за свежие. Проверено, что OpenAI принимает browser authorization URL и перенаправляет на страницу входа; также проверены локальный callback, PKCE, отказ от чужого `state`, отмена, тесты протокола с моделируемыми ответами и Android-интерфейс. Полный вход и реальные лимиты конкретной подписки требуют проверки владельцем аккаунта на телефоне.

## Приватность

Пароль вводится только в браузере OpenAI. Access/refresh tokens шифруются AES-GCM; ключ хранится в Android Keystore, шифротекст — в закрытых настройках приложения. Резервное копирование и перенос данных приложения отключены. Токены не попадают в логи, Git, APK или GitHub Releases. Перенаправления авторизованных запросов запрещены, HTTPS проверяется штатным Android trust store. Внешние запросы приложения идут только к `auth.openai.com`, `chatgpt.com`, `platform.claude.com` и `api.anthropic.com`. Во время входа временно работает локальный callback на самом телефоне; он закрывается после входа, отмены или тайм-аута, не отражает код/токены в HTML и запрещает кеширование страницы. На «Отключить аккаунт» удаляются локальные токены и кеш; это не глобальный выход из аккаунта OpenAI.

## Сборка

Нужны JDK 17+ (проверено на JDK 21), Android SDK Platform 35 и Build Tools 35.0.0. Gradle 8.11.1 и Android Gradle Plugin 8.9.2 зафиксированы; wrapper проверяет SHA-256 дистрибутива.

```sh
cd limit-pulse
export ANDROID_HOME=/path/to/android-sdk
./gradlew --no-daemon testDebugUnitTest lintRelease assembleRelease
```

Результат — `app/build/outputs/apk/release/app-release-unsigned.apk`. Для локальной отладки используйте `./gradlew assembleDebug` и `adb install -r app/build/outputs/apk/debug/app-debug.apk`. CI проверяет тесты, lint и release-сборку, сохраняет **неподписанный** APK как артефакт; он не является устанавливаемым релизом.

Подписать release своим ключом:

```sh
export LIMITPULSE_KEYSTORE=/secure/path/limit-pulse.jks
export LIMITPULSE_PASSWORD_FILE=/secure/path/keystore-password.txt
bash scripts/sign-release.sh
```

Пароль считывается из защищённого файла, не из аргументов командной строки. Подпись проверяется `apksigner verify`; итоговый APK, SHA256SUMS и публичный сертификат создаются в `app/build/outputs/release/`. **Для обновления поверх установленного APK требуется тот же ключ подписи.** Ключ первого выпуска сохранён вне репозитория в облачной рабочей среде; ключ и пароль никогда не публикуются в Releases. Перед удалением среды сохраните их отдельно в защищённом хранилище.

## Проверки

JUnit проверяет расчёт и истечение лимитов, оба способа OAuth, PKCE по RFC 7636, реальный локальный callback, защиту `state`, отсутствие секретов в странице возврата, отмену/тайм-аут и обновление токенов. Robolectric на Android API 26 и 35 проверяет Activity, экран browser login, deep link без возможности подмены авторизации, уведомление службы входа и RemoteViews виджета. SDK для этих тестов получает Gradle; тесты используют локальные артефакты и не пишут в домашнюю папку пользователя. Эти проверки не заменяют вход в личный аккаунт, проверку Android Keystore на физическом устройстве и поведение фоновых задач конкретного производителя.
