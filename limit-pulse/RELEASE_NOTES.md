**Limit Pulse 0.4.0** — лимиты Claude рядом с Codex.

### Что нового

- Раздел **Claude** в приложении: остаток 5-часового и недельного лимитов подписки Claude Pro/Max, отсчёт до сброса, недельные лимиты Opus/Sonnet и дополнительное использование, если Anthropic их возвращает.
- Отдельный виджет **«Limit Pulse · Claude»** в том же ярком стиле; виджет Codex остаётся без изменений. Оба можно поставить на экран.
- Напоминания за час до сброса теперь и для Claude — отдельно для 5-часового и недельного окна.
- Вход в Claude через браузер (как в Claude Code, OAuth + PKCE). Запасной вариант — вставить код со страницы Claude.
- Приложение запрашивает у Claude только доступ к профилю (`user:profile`): чтение лимитов без отправки сообщений и без создания API-ключей. Токены шифруются через Android Keystore, отдельно от OpenAI.

### Проверки

Новые тесты: URL авторизации и PKCE, отказ от кода с чужим `state`, обмен кода и обновление ротируемого refresh token, заголовки запроса лимитов, разбор `utilization`/`resets_at`, виджет Claude, экран входа по коду, напоминания Claude в отдельных слотах и их независимость от выхода из Codex. Вход в реальный аккаунт Claude проверяется владельцем на телефоне.

Android 8.0+, package `dev.limitpulse.app`, versionCode 4.
