# PushDuel

Telegram Mini App для онлайн-дуэлей на отжиманиях. Телефон лежит на полу, камера через нейросеть MediaPipe Pose
находит плечи и кисти и сама считает повторы. Соперник отжимается в то же время, сервер ведёт таймер и судит.
Вокруг дуэлей построено сообщество: рейтинг, кланы, цель недели, приглашения, боевой пропуск с премиумом за
Telegram Stars и настоящими подарками Telegram.

Стек: **Next.js 16 (App Router, React 19) и WebSocket в одном процессе Node.js**. Интерфейс — плоский
древнегреческий стиль без градиентов и бликов: сплошные заливки, контуры, меандр, лавр, колонны, амфоры,
римские цифры и Везувий. Иконки нарисованы в SVG (`components/Icon.jsx`) в духе вазовой росписи, а все
остальные эмодзи CSS превращает в одноцветные силуэты цвета текста — как фигуры на вазе.
Светлая тема «Эгея» — синий, белый и охра; тёмная «Амфора» — чёрный, красный и охра. Охра отдана главному
действию и наградам. Заголовки — Cormorant SC, текст и цифры — Manrope.

**Конструкторы.** Аватар собирается из деталей: фигура (открываются в пропуске, магазине и за приглашения),
форма (шестигранник, медальон, щит, плита), окантовка (простая, двойная, меандр, жемчуг, лавр, канат) и цвета
фона, фигуры и окантовки. Рамки из пропуска перекрашивают окантовку. Герб клана собирает капитан: щит, поле
с делением (рассечён, пересечён, скошен, стропило, четверти, крест), два цвета, знак и его цвет, кайма.
Детали и проверка — `lib/heraldry.js`.

**Главная («Бой») не прокручивается:** сверху профиль и валюта, под ними серия дней кружками и отсчёт
до извержения (окно с вулканом, календарём серии и прогнозом статуи), по центру нарисованная арена
(листается стрелками) с кнопкой «В бой» и выбором режима (упражнение — пока отжимания; формат — рейтинг,
с другом, тренировка, бот), внизу амфоры-наборы. Вкладки: Агора · Пропуск · Бой · Клан · Слава.
Конец сезона = извержение Везувия. Картинки арен пока векторные заглушки (`lib/client/arenaArt.js`),
их заменят сгенерированные ассеты.

## Что умеет

**Бой**
- Счёт повторов по скелету: глубина считается по расстоянию «плечи — кисти» относительно верхней точки за
  последние 2,5 с, поэтому калибровка не нужна. Три режима строгости.
  Проверено на реальном видео дуэли: 35 повторов против 34 у оригинала, тест `test/counter.test.mjs`.
- Перед матчем идёт интро «VS»: горизонтальные карточки игроков с жетонами и наклейками влетают — одна слева,
  другая справа, — удар и вспышка, а потом уносятся дальше: верхняя вправо, нижняя влево.
- Музыка боя синтезируется на лету (WebAudio, без файлов), в последние 10 секунд темп растёт.
- Комбо ×5, ×10… с надписями, всплески на каждый повтор, звук и вибрация через Telegram HapticFeedback.
- Режимы: **рейтинговая дуэль** (подбор по Эло), **дуэль с другом** (комната с кодом или вызов из профиля игрока:
  бот присылает вызов в личку), **бой с ботом**, **тренировка**.
- Экран не гаснет (Wake Lock), свайп вниз не закрывает приложение, а выход из боя спрашивает подтверждение.

**Сообщество**
- Рейтинги: общий по Эло, за неделю по отжиманиям, среди друзей и кланов.
- Кланы до 30 человек: герб, девиз, недельный зачёт, приглашение ссылкой. Если капитан уходит,
  капитаном становится самый активный участник.
- **Спарринги в клане**: отдельная очередь только среди соклановцев (или вызов конкретного участника из
  состава, где видно, кто в сети). Без влияния на Эло, но с опытом.
- **Войны кланов**: капитан вызывает другой клан, капитан соперников принимает вызов (на ответ 12 часов,
  бот присылает уведомление). Война идёт 24 часа: каждое отжимание участника в любом режиме — очко клану,
  победа в «бою войны» против бойца вражеского клана — ещё +50. Победители (вклад от 20 повторов) получают
  кристаллы и эпический набор, проигравшие — монеты.
- Цель недели для всего сообщества: всем, кто сделал хотя бы 50 повторов, дают +300 опыта и титул.
- Лента событий: победы, серии, рекорды, новые кланы, уровни пропуска, покупки премиума.
- Профили игроков с вызовом на дуэль; друзья появляются после дуэлей и приглашений.
- Реферальная программа: +200 опыта пригласившему и +100 приглашённому. За 1, 3, 5 и 10 друзей открывается
  музыка для боя (Синтвейв, 8-бит, Драм-н-бейс, Эпик), а также аватар, титул и рамка.

**Прогресс**
- Боевой пропуск на 30 уровней. Опыт начисляется за повторы, победы, комбо, серию побед
  (плюс до +5 Эло сверху), первую победу дня и ежедневные задания. Серия дней умножает опыт до ×2.
- Косметика: **скины-костюмы поверх тела** (Кости, Робот, Ниндзя, Рыцарь, Супергерой, Кибер, Дух огня),
  стили скелета, эффекты повтора, рамки аватара, эффекты победы, титулы и музыка. В примерочной синтетический
  человечек отжимается с выбранными эффектами.
- Жетоны четырёх редкостей за достижения. Три из них показываются на карточке игрока в интро.

**Наклейки, арены, магазин**
- Валюта: монеты и кристаллы. Кристаллы **только зарабатываются** (задания дня по 5 💎,
  дорога трофеев, наборы, победы) и за звёзды не продаются: иначе наборы со случайными наклейками стали бы
  платными лутбоксами.
- **Наборы наклеек** за каждую победу в рейтинге идут по фиксированному циклу: обычный → редкий → эпический →
  легендарный. Слотов 4, наборы открываются по таймеру по одному, раньше срока — за кристаллы.
  Внутри 3–6 наклеек с гарантией редкости, монеты, опыт. Сверх трёх копий наклейка превращается в монеты.
- **Открытие набора — разбить вазу.** Шесть тапов: с каждым ваза вздрагивает, на ней прорисовывается новая
  трещина, откалываются кусочки, телефон коротко вибрирует (сильнее к концу). На шестом ваза разлетается на
  осколки, и только потом по одной показываются наклейки. Экран полноэкранный и без текста: только ваза
  и ромбики оставшихся ударов.
- 36 наклеек четырёх редкостей. **Эпические и легендарные — голографические**: переливаются от наклона
  телефона. Источник наклона — `Telegram.WebApp.DeviceOrientation` (Bot API 8.0+), запасные варианты —
  `deviceorientation` браузера и движение мыши. Один глобальный слушатель пишет CSS-переменные
  `--tilt-x/--tilt-y`, поэтому голограммы не нагружают React.
- **Наклейки клеятся на карточку игрока**: перетаскивание, поворот, размер, до 6 штук. Соперник видит карточку
  в интро «VS». Есть альбом коллекции.
- Арены и **дорога славы**: кубки — это рейтинг. 7 арен от Агоры до Олимпа и 18 наград на дороге
  (наборы, монеты, кристаллы, рамки, титулы). Дорога — отдельный полноэкранный экран: первая арена внизу,
  листаем вверх к вершине Олимпа. Сзади сплошное полотно, где арены перетекают одна в другую, по центру
  извилистая дорога с вехами, справа награды, внизу кнопка «Назад».
- Магазин: три наклейки и предмет косметики дня за монеты, наборы за кристаллы, буст опыта ×2,
  премиум-пропуск за звёзды.

**Пояса и турниры**
- **Пояса чемпионов:** на каждой арене один пояс и один владелец.
  - Свободный пояс забирает первый, кто выиграл рейтинговый бой на этой арене.
  - Победил чемпиона своей арены в рейтинге или в **титульном бою** (вызов из профиля, бот присылает
    чемпиону приглашение) — пояс твой.
  - Чемпион, упавший ниже арены, освобождает пояс.
  - Кто держит пояс на смене недели, получает кристаллы и набор, а лента сообщает об этом.
- **Два турнира «до трёх поражений»**, вход за кристаллы, играть можно в любое время.
  - **Малый** — 10 💎, до 6 побед. Награды растут с каждой победой: монеты → редкие → эпические →
    легендарный набор и кристаллы.
  - **Большой** — 100 💎, до 12 побед. С 9 побед добавляются подарки Telegram (15, 25, 50 и 100 ★),
    за 12 побед — уникальная наклейка «Чемпион».
  - Отдельная очередь для каждого турнира, ничья не считается. Забег кончается на 3-м поражении или
    на максимуме побед, награда приходит в почту. Если подарок не ушёл, его можно отправить повторно.
  - Исход решает только сила, а кристаллы только зарабатываются, так что это не лотерея.
- Награды за пояса и турниры приходят в «почту» на главной.

**Премиум-пропуск за Telegram Stars**
- Покупка через `createInvoiceLink` в валюте `XTR`. Бот проверяет `pre_checkout_query` и выдаёт пропуск
  по `successful_payment`; повторное уведомление о платеже второй раз пропуск не выдаёт.
- На премиум-треке подарки Telegram на 8, 16, 24 и 30 уровнях (по умолчанию за 15, 25, 50 и 100 ★, всего 190 ★
  при цене 299 ★), эксклюзивные скины и эффекты, а также +20% опыта.
- Подарки — **гарантированные** награды уровней, а не случайный розыгрыш: платный вход со случайным призом
  юридически похож на лотерею. Бот отправляет подарок методом `sendGift` из своего баланса звёзд. Если звёзд
  не хватает, подарок помечается и его можно забрать позже.

## Как устроено

```
server.mjs              один HTTP-сервер: Next.js (страницы и /api) + WebSocket /ws + бот
lib/counter.js          счётчик повторов по точкам скелета (общий)
lib/pass.js             пропуск, косметика, жетоны, задания, опыт (общий: клиент и сервер)
lib/duel.js             Эло, звания, бот-соперник
lib/stickers.js         каталог наклеек, редкости, наборы (общий)
lib/economy.js          арены, дорога трофеев, магазин, цикл наборов (общий)
lib/compete.js          пояса, турниры, войны клановы, войны кланов: правила и призы (общий)
lib/server/economy.js   наборы, коллекция, карточка, почта, покупки — только на сервере
lib/server/compete.js   владельцы поясов, турнирные забеги, войны кланов, итоги и призы
lib/client/tilt.js      наклон телефона для голограмм (DeviceOrientation Telegram)
lib/server/store.js     игроки, кланы, лента, начисление прогресса; данные в JSON-файле
lib/server/hub.js       подключения, подбор по рейтингу, комнаты, вызовы, матчи (сервер — судья)
lib/server/api.js       REST: профиль, рейтинги, кланы, тренировки, покупка, подарки
lib/server/premium.js   оплата звёздами и выдача подарков
lib/server/telegram.js  проверка подписи initData, бот на long polling
lib/client/*            Telegram SDK, сеть, MediaPipe, эффекты, скины, музыка, звук
components/*            экраны: главная, рейтинг, клан, пропуск, профиль, бой, итог, интро
app/api/[...path]       тонкий route handler → lib/server/api.js
```

- **Вход**: клиент отправляет `Authorization: tma <initData>`, а сервер проверяет HMAC-подпись токеном бота
  и срок `auth_date`. Вне Telegram, для разработки, используется гостевой токен из `localStorage`.
- **Античит на уровне правдоподобия**: сервер принимает повторы только во время боя и не чаще раза в 280 мс.
  Повторы тренировки проверяются по времени. Распознавание идёт на устройстве игрока, поэтому полной
  защиты от подделки нет.
- Route handlers Next.js собираются отдельным бандлом, поэтому `server.mjs` передаёт им общее состояние
  через `globalThis.__pushduel`.

## Запуск

```bash
cd pushup-duel
npm install
npm run dev            # http://localhost:3000, гостевой вход, премиум выдаётся без оплаты
```

```bash
npm test               # счётчик на реальном видео, сервер по WebSocket, оплата и подарки, наклейки, пояса, турниры, войны кланов
npm run build && npm start
```

Docker:

```bash
docker build -t pushduel .
docker run -p 3000:3000 -v pushduel-data:/data --env-file .env pushduel
```

Переменные окружения описаны в [`.env.example`](.env.example).

## Подключение к Telegram

1. Создайте бота в [@BotFather](https://t.me/BotFather) и положите токен в `BOT_TOKEN`, а имя — в `BOT_USERNAME`.
2. Опубликуйте сервер по **HTTPS** (камера в Telegram работает только по HTTPS) и укажите адрес в `WEBAPP_URL`.
3. В BotFather: `/newapp`, чтобы получить ссылку `t.me/<бот>/<имя>` (имя положите в `APP_SHORT_NAME`).
   Также можно настроить Bot Settings → Configure Mini App.
4. Запустите сервер. Бот сам поставит кнопку меню «Играть» и будет отвечать на `/start` и платежи.
5. **Подарки**: пополните баланс звёзд бота. Звёзды от продаж пропуска тоже приходят на баланс бота.
   Пока звёзд нет, подарки встают в очередь «забрать позже».

Ссылки, которые раздаёт приложение: `ref_<id>` (приглашение), `duel_<код>` (комната дуэли), `clan_<код>` (клан).

## Ограничения

- Данные хранятся в одном JSON-файле в памяти процесса. Этого хватит на тысячи игроков; для большего масштаба
  нужна база данных и несколько инстансов с общей очередью.
- Подсчёт рассчитан на съёмку спереди (телефон на полу перед игроком). Сбоку тоже работает, но менее надёжно.
- Возврат звёзд (`refundStarPayment`) пока делается вручную.
