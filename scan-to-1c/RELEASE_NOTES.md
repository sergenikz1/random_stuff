**Scan2-1C.exe** — распознаёт сканы первичных документов (PDF, JPG, PNG, TIFF, BMP, GIF, WEBP, HEIC)
и загружает их в 1С:Предприятие 8.3.

### Новое в 1.1.0

**Распознавание ИИ через OmniRoute**

- Реквизиты может извлекать ИИ-модель: программа понимает любой макет счёта, акта или УПД, а не только типовые формы.
- Модели подключаются через OmniRoute — один адрес для множества провайдеров. Настройка: «Настройки» → «Распознавание ИИ».
- Модели уходят текст после OCR и картинки страниц; ответ проверяется по контрольной сумме ИНН и сходимости НДС.
- Если ИИ недоступен, документ распознаётся шаблонами, как раньше.

**Автообновление**

- При запуске программа сама проверяет релизы на GitHub и в фоне скачивает новую версию.
- Перед установкой проверяет контрольную сумму SHA-256 и что новая версия запускается; повреждённое обновление не ставится.
- Если документов в списке нет, сразу перезапускается в новой версии, иначе спрашивает. Путь к программе и ярлыки не меняются.
- Включается и выключается в «Настройках», там же кнопка «Проверить сейчас».
- Файл в релизе теперь называется `Scan2-1C.exe` без номера версии, обработка 1С — `Zagruzka-skanov.bsl`.

Версия 1.0.0 обновляться не умела: замените её на эту вручную один раз, дальше обновления придут сами.

### Что умеет программа

- Находит тип документа (счёт, УПД, счёт-фактура, ТОРГ-12, акт), номер, дату, ИНН/КПП и названия сторон, сумму, ставку и сумму НДС, банковские реквизиты.
- Проверяет ИНН по контрольной сумме и сходимость НДС, подсвечивает документы, которые стоит проверить.
- Загружает в базу через OData: ищет контрагента по ИНН (создаёт, если нет), создаёт непроведённый документ, не делает дублей.
- Или складывает JSON + скан в папку обмена для обработки `Zagruzka-skanov.bsl` (в репозитории — `scan-to-1c/1c/ЗагрузкаСканов.bsl`).

Установка не нужна: OCR Tesseract с русским языком встроен в exe. Подробности — в `scan-to-1c/README.md`.
