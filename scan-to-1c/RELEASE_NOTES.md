**Scan2-1C.exe** — распознаёт сканы первичных документов (PDF, JPG, PNG, TIFF, BMP, GIF, WEBP, HEIC)
и загружает их в 1С:Предприятие 8.3.

### Какой файл скачать

| Windows | Файл |
|---|---|
| 8.1, 10, 11 | `Scan2-1C.exe` |
| 7 SP1 | `Scan2-1C-win7.exe` |

### Новое в 1.3.0 — поддержка Windows 7

- Отдельная сборка `Scan2-1C-win7.exe` для Windows 7 SP1: на Python 3.8 (последний, что работает на Windows 7),
  с Universal CRT внутри — без ошибок «отсутствует api-ms-win-core-path-l1-1-0.dll», «VCRUNTIME140.dll»
  и «Failed to load Python DLL». Работает и на новых Windows.
- Каждая DLL сборки для Windows 7 при выпуске проверяется: она не должна требовать функций Windows 8 и новее.
- Автообновление обновляет каждую сборку своим файлом: версия для Windows 7 не получит несовместимый exe.
- На Windows 7 должно стоять обновление KB2533623 (2011 г., входит в обычные обновления Windows 7 SP1).

### Новое в 1.2.0

- **Реквизиты видны сразу.** Добавленный документ выделяется сам, и поля справа заполняются по мере распознавания —
  раньше документ распознавался, но поля оставались пустыми, пока не щёлкнуть по нему в списке.
- **Несколько документов в одном PDF.** Скан «ТОРГ-12 на двух листах + счёт-фактура» делится на отдельные документы:
  в списке появляются «файл.pdf, стр. 1–2» и «файл.pdf, стр. 3», каждый со своими реквизитами.
- **Строки товаров без ИИ** из счетов-фактур, УПД, счетов на оплату и актов: артикул, единица, количество, цена,
  суммы, «Без НДС», страна, номер ГТД. Если «Всего к оплате» прочиталось неверно, итог берётся по сумме строк.
- **Мелкий шрифт шапки.** Если на странице не нашлись ИНН или номер, она перечитывается крупнее — так находятся
  поставщик и плательщик в шапке ТОРГ-12.
- **Точнее дата и номер ТОРГ-12:** берутся из рамки «Номер документа / Дата составления», а не из рамки транспортной
  накладной или реквизитов формы («России от 25.12.98»); даты вида «17.10. 2026» читаются.

### Новое в 1.1.0

**Удобнее и точнее на реальных документах**

- Распознавание начинается сразу после добавления файлов — нажимать ничего не нужно.
- «Объединить страницы»: несколько фото одного документа (например, ТОРГ-12 на двух листах) — один документ.
- Фото с телефона, снятые боком, разворачиваются надёжнее; мелкие снимки увеличиваются перед распознаванием.
- Суммы с любыми разделителями тысяч («87.340,00», «21,835.00»); итог находится, даже если строка «Итого» не прочиталась.
- Новые поля: основание, документ об отгрузке, грузоотправитель, грузополучатель; ИНН/КПП без подписи «ИНН».
- Строки товаров (с распознаванием ИИ): артикул, количество, цена, НДС, страна, номер ГТД — и загрузка их в табличную часть «Товары» в 1С.

**Распознавание ИИ через OmniRoute**

- Реквизиты может извлекать ИИ-модель: программа понимает любой макет счёта, акта или УПД, а не только типовые формы.
- Модели подключаются через OmniRoute — один адрес для множества провайдеров. Настройка: «Настройки» → «Распознавание ИИ».
- Модели уходят текст после OCR и картинки страниц; ответ проверяется по контрольной сумме ИНН и сходимости НДС.
- Если ИИ недоступен, документ распознаётся шаблонами, как раньше.

**Автообновление**

- При запуске программа сама проверяет релизы на GitHub и в фоне скачивает новую версию.
- Перед установкой проверяет контрольную сумму SHA-256 и что новая версия запускается; повреждённое обновление не ставится.
- Если документов в списке нет, сразу перезапускается в новой версии, иначе спрашивает. Путь к программе и ярлыки не меняются.
- Включается и выключается в «Настройках», там же кнопка «Проверить сейчас».
- Файл в релизе теперь называется `Scan2-1C.exe` без номера версии, обработка 1С — `Zagruzka-skanov.bsl`.

Версия 1.0.0 обновляться не умела: замените её на эту вручную один раз, дальше обновления придут сами.

### Что умеет программа

- Находит тип документа (счёт, УПД, счёт-фактура, ТОРГ-12, акт), номер, дату, ИНН/КПП и названия сторон, сумму, ставку и сумму НДС, банковские реквизиты.
- Проверяет ИНН по контрольной сумме и сходимость НДС, подсвечивает документы, которые стоит проверить.
- Загружает в базу через OData: ищет контрагента по ИНН (создаёт, если нет), создаёт непроведённый документ, не делает дублей.
- Или складывает JSON + скан в папку обмена для обработки `Zagruzka-skanov.bsl` (в репозитории — `scan-to-1c/1c/ЗагрузкаСканов.bsl`).

Установка не нужна: OCR Tesseract с русским языком встроен в exe. Подробности — в `scan-to-1c/README.md`.
