# Scryer TV — клиент Scryer для телевизоров

Android TV приложение (APK) для [Scryer](https://github.com/scryer-media/scryer) —
self-hosted менеджера фильмов, сериалов и аниме (аналог Sonarr + Radarr + Seerr).
Сам Scryer работает на домашнем сервере/NAS и умеет искать релизы, качать и
раскладывать файлы; у него есть веб-интерфейс, но нет приложения для ТВ.
Scryer TV даёт управлять им с пульта: посмотреть, что есть и что качается,
найти новый фильм и добавить его в библиотеку, не вставая с дивана.

Проект живёт в каталоге `scryer-tv/` и не связан с остальными проектами репозитория.

## Что умеет

- **Главный экран** в стиле Android TV (leanback):
  - «Загрузки» — очередь с прогрессом, обновляется каждые 10 секунд;
  - «Скоро выйдет» — календарь серий на две недели вперёд (есть / ждём);
  - «Новое в фильмах / сериалах / аниме» — последние добавленные тайтлы;
  - подборки «Обзора» Scryer (персональные и общие рекомендации);
  - меню: поиск, вся библиотека по разделам, очередь, настройки.
- **Поиск** (в том числе голосовой) сразу в своей библиотеке и в базе
  метаданных Scryer: фильмы, сериалы и аниме отдельными полками.
- **Карточка тайтла**: постер, фон, описание, рейтинг, качество, сколько серий есть.
  - Не в библиотеке — «Добавить и скачать» (для сериалов: все серии или только новые).
    Scryer сам найдёт и скачает релиз. Если у пользователя нет права добавлять,
    уходит запрос на одобрение администратору.
  - В библиотеке — «Найти и скачать» (лучший релиз сейчас), включить/выключить
    отслеживание, «Смотреть» — открыть тайтл в Plex/Jellyfin/Emby, если сервер
    медиатеки подключён к Scryer.
  - Полка «Похожее».
- **Библиотека** сеткой постеров по разделам, с подгрузкой при прокрутке.
- **Очередь загрузок** отдельным экраном, обновляется каждые 5 секунд.

## Онлайн-просмотр (1.1)

Встроенный плеер Media3 играет видео без предварительной загрузки файла.
При первом запуске можно сразу смотреть онлайн, не подключая сервер Scryer.
После подключения сервера раздел доступен через «Смотреть онлайн» в главном меню,
в карточке фильма/сериала и на экране ошибки подключения.

- **Rutube:** поиск по названию с подгрузкой результатов, открытие ссылки на видео.
  Клиент использует только контентный поток из API, без рекламного веб-плеера.
- **Сериалы:** «Серии и сезоны» показывает нумерованные серии одного сериала от
  одного автора. Распознаются `S01E02`, `1 сезон 2 серия`, `серия 2`.
  В конце серии включается следующий номер, затем первый эпизод следующего сезона.
  Пропуск номера или неизвестная нумерация останавливают автоматическую очередь.
  Поиск ограничен первыми восемью страницами результатов Rutube.
- **M3U:** «Открыть ссылку» импортирует плейлист до 200 видео / 2 МБ. Серии
  проигрываются в порядке файла внутри `group-title`; разные сериалы стоит
  поместить в разные группы. HLS-манифест `.m3u8` считается одним видео, а его
  сегменты никогда не превращаются в отдельные серии.
- **Прямые ссылки:** HTTP/HTTPS MP4, MKV, WebM, HLS и DASH, без веб-страниц.
- Позиция сохраняется каждые пять секунд и при выходе, есть история и избранное.
  Плеер поддерживает пульт, паузу, перемотку ±10 секунд, аудиофокус и выбор
  максимального качества. В фоне воспроизведение останавливается.
- За минуту до конца запрашивается адрес следующей серии; за 20 секунд появляется
  кнопка перехода с возможностью отменить автопереход. Настройка автоперехода
  сохраняется в «Настройках плеера».

Пример M3U для собственного каталога:

```m3u
#EXTM3U
#EXTINF:-1 group-title="Сериал",Сезон 1 · Серия 1
https://media.example.org/series/s01e01.mp4
#EXTINF:-1 group-title="Сериал",Сезон 1 · Серия 2
https://media.example.org/series/s01e02.m3u8
```

Автоматический поиск реализован для Rutube. Страницы LordFilm и VK не являются
поддерживаемыми источниками: их веб-плееры, авторизация и защита не обходятся.
Прямую ссылку на доступный поток можно открыть отдельно или включить в M3U.
Реклама, вшитая в сам видеофайл/поток, не удаляется. Доступность Rutube зависит
от региона и сети: в облачном окружении проверка API вернула HTTP 403;
живое воспроизведение на проекторе ещё нужно проверить.

Просмотр скачанной библиотеки Scryer по-прежнему открывает Plex/Jellyfin/Emby.
Ключ доступа Scryer не передаётся онлайн-источникам: у них отдельный HTTP-клиент.

## Подключение к серверу

При первом запуске приложение спрашивает адрес Scryer — тот же, что в браузере,
например `http://192.168.1.10:8080` (если Scryer за обратным прокси с путём —
вместе с путём: `https://home.example.com/scryer`). Дальше один из трёх способов:

1. **Логин и пароль** (и код 2FA, если включён). Приложение входит и выпускает
   себе бессрочный API-ключ «Scryer TV», пароль не сохраняется. Если сервер не дал
   выпустить ключ (например, просит свежее подтверждение 2FA), приложение работает
   на обычной сессии — когда она истечёт, попросит войти снова.
2. **Без пароля** — если вход в Scryer выключен или включён обход для локальной сети.
3. **Готовый API-ключ** (`ska_…`) из веб-интерфейса: Настройки → Безопасность → API-ключи.

Отозвать доступ телевизора — удалить ключ «Scryer TV» в веб-интерфейсе.
«Настройки → Сменить сервер или выйти» в приложении стирает ключ с телевизора.

Проверено по схеме GraphQL Scryer **v0.21.20** (`api/graphql/schema.graphql`).

## Сборка

### Через GitHub Actions (ничего ставить не нужно)

Workflow `.github/workflows/scryer-tv.yml` собирает APK на каждый push в
каталог `scryer-tv/`. Свежий APK из ветки `main` лежит в предрелизе
**`scryer-tv-latest`** (раздел Releases), а также в артефактах запуска
(`ScryerTV-apk`): **Actions → нужный запуск → Artifacts**.

Запустить вручную: **Actions → Scryer TV — сборка APK → Run workflow**.

### Локально

Нужен JDK 17 и Android SDK (`ANDROID_HOME`), сеть до `dl.google.com` и
Maven Central:

```bash
cd scryer-tv
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk

# Проверки очереди серий, M3U и сериализации:
./gradlew testDebugUnitTest
```

Без секретов сборка подписывается отладочным ключом — APK устанавливается,
но обновить его позже релизным ключом уже не получится (только переустановка).

### Подпись релизным ключом

```bash
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias scryertv
base64 -w0 release.jks   # значение для секрета SCRYERTV_KEYSTORE_BASE64
```

Секреты: `SCRYERTV_KEYSTORE_BASE64`, `SCRYERTV_KEYSTORE_PASSWORD`,
`SCRYERTV_KEY_ALIAS`, `SCRYERTV_KEY_PASSWORD`. При локальной сборке те же
значения задаются переменными окружения (`SCRYERTV_KEYSTORE_FILE` вместо base64).

## Установка на телевизор

1. Скачайте APK из релиза `scryer-tv-latest`.
2. Включите на ТВ установку из неизвестных источников.
3. Поставьте любым способом:
   - `adb connect <ip-телевизора>:5555 && adb install -r ScryerTV-*.apk`
   - или через файловый менеджер / «Send files to TV» с флешки.
4. Приложение появится в списке приложений Android TV (и в обычном лаунчере —
   `leanback` помечен как необязательный, поэтому ставится и на приставки).

Требования: Android 5.0+ (minSdk 21), сервер Scryer в той же сети (или доступный
по адресу из интернета).

## Структура

```
scryer-tv/app/src/main/java/org/scryertv/client/
├── data/        ScryerApi (HTTP + авторизация), Queries (все GraphQL-запросы),
│                Repository (сценарии и разбор ответов), модели, Prefs
├── ui/          главный экран, поиск, карточка тайтла, библиотека, очередь,
│                вход, настройки
└── util/        форматирование размеров, дат, статусов
```

Все запросы к Scryer собраны в одном файле — `data/Queries.kt`. Если в новой
версии Scryer поменяется схема, правится только он:

| Что | GraphQL |
| --- | --- |
| Вход | `login`, затем `createMyApiKey` |
| Вход без пароля | `GET /authless-client`, затем `createMyApiKey` |
| Главный экран | `titles(facet, sort: ADDED)` со счётчиком `totalCount` |
| Календарь | `calendarEpisodes(startDate, endDate)` |
| Обзор | `discoveryHome` |
| Поиск | `titles(query)`, `searchMetadataMulti` |
| Карточка | `title(id)` с `playbackLinks` и `moreLikeThis` |
| Очередь | `downloadQueuePage` |
| Добавить | `addTitle`, при нехватке прав — `submitMediaRequest` |
| Скачать | `queueBestRelease(scope: { title: true })` |
| Отслеживание | `setTitleMonitored` |

Запросы проверены валидатором `graphql-js` против схемы Scryer v0.21.20.

## Ограничения

- Настройка Scryer (индексаторы, клиенты загрузки, профили качества, правила)
  остаётся в веб-интерфейсе — с пульта это неудобно.
- Добавление идёт в библиотеку по умолчанию для раздела, с её профилем качества.
- Нет выбора конкретного релиза вручную (интерактивного поиска) — только
  «лучший релиз» по правилам Scryer.
- Приложение неофициальное и не связано с авторами Scryer.
